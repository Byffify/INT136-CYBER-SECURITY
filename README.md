# Bitdefender Total Security — EICAR Case Study

Thai interactive presentation: 14 main slides and 2 appendices.

## Run locally

```sh
npm ci
npm run dev -- --port 5175
```

## Production build

```sh
npm run build
npm run preview
```

Use Space or Right Arrow to advance, Left Arrow to go back, R to restart a slide, M for the slide menu, N for speaker notes, and F for fullscreen.

Source: `src/`. Images and fonts: `public/`. Brief: `BITDEFENDER_SLIDE_CONTENT_BRIEF.md`. Reference provenance: `REFERENCE_ADAPTATION.md`.

The slides describe a single-machine EICAR experiment, not a general malware detection benchmark. The presentation includes supplied member portraits and student IDs.
